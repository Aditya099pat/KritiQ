# KritiQ — Movies & Series Review Website

KritiQ is a modern movie and series review website built with HTML, CSS, and vanilla JavaScript. It presents a cinematic homepage, detailed title pages, ratings, wishlist interactions, and a polished dark-red visual identity.

## Features

- Cinematic landing page with hero carousel
- Movie and series detail pages
- Login and create-account pages
- Wishlist and like interactions using browser local storage
- Search bar UI
- Responsive dark theme inspired by streaming platforms
- Custom KritiQ favicon
- Professional red, black, and white branding

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Aditya099pat/KritiQ.git
```

2. Open the project folder:

```bash
cd KritiQ
```

3. Open `index.html` in your browser.

For development, you can also open the folder in VS Code and run it using the Live Server extension.

## Screenshots Setup

Create a folder named `screenshots` in the project root and add your screenshots with these names:

```text
screenshots/homepage.png
screenshots/login-page.png
screenshots/create-account.png
screenshots/movie-details.png
```

The screenshots will automatically appear in this README on GitHub once pushed.

## Deployment with GitHub Pages

1. Open your GitHub repository.
2. Go to **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, select:
   - Branch: `main`
   - Folder: `/root`
5. Save the settings.

GitHub will generate a live website URL after a short delay.
